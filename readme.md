# RenkuBASIC

RenkuBASIC is a BASIC dialect for the Renku Operating System.

It is based on the yabasic dialect and in its first iterations, aims to offer both ncurses and Haiku/RenkuOS API calls.
Backwards compatibility with the yab dialect is an initial design goal, but the language will be extended and will be rebased on the latest yabasic versions from time to time.
