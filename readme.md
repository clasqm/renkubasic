# RenkuBASIC

RenkuBASIC is a BASIC dialect for the Renku Operating System.

It is based on Marc-Oliver Ihm's [yabasic](http://2484.de/yabasic/) dialect and in its first iterations, aims to offer both [ncurses](https://invisible-island.net/ncurses/announce.html) and [Haiku/RenkuOS API](https://www.haiku-os.org/docs/api/) calls. Backwards compatibility with the [yab](https://github.com/lorglas/yab) dialect is an initial design goal, but the language will be extended with new abilities and will be rebased on the latest yabasic versions from time to time.
